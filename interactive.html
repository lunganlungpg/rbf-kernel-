1 The RBF Kernel Formula

Gaussian Radial Basis Function

K(x, x') = exp(-γ ‖x - x'‖²)
K(x, x')

Similarity measure between two data points in the transformed feature space

γ (gamma)

Controls the width of the Gaussian. Higher γ = narrower peak = more complex boundaries

‖x - x'‖²

Squared Euclidean distance between the two input vectors

4 How RBF Kernel Works

📊

Input Space

Data points exist in original feature space where classes may not be linearly separable

🔄

Implicit Mapping

RBF kernel implicitly maps data to infinite-dimensional space using the kernel trick

📐

Similarity Measure

Computes dot products in high-dimensional space as similarity between points

✂️

Linear Separation

Non-linear boundaries in input space become linear hyperplanes in feature space

✓ Key Properties

  • ● Bounded output: K(x,x') always between 0 and 1
  • ● Self-similarity: K(x,x) = 1 (point is identical to itself)
  • ● Locality: Points far apart have near-zero similarity
  • ● Universal approximator: Can represent any continuous function

⚠ Considerations

  • ● γ tuning: Too high → overfitting, too low → underfitting
  • ● Feature scaling: Always normalize features before using RBF
  • ● Computational cost: O(n²) for kernel matrix computation
  • ● Cross-validation: Use grid search for optimal γ and C

5 Implementation Example

Python — scikit-learn
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import GridSearchCV

# Always scale features before RBF kernel
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_train)

# Create SVM with RBF kernel
svm_rbf = SVC(kernel='rbf', gamma=0.5, C=1.0)

# Grid search for optimal hyperparameters
param_grid = {
    'gamma': [0.01, 0.1, 0.5, 1.0, 10],
    'C': [0.1, 1, 10, 100]
}
grid_search = GridSearchCV(svm_rbf, param_grid, cv=5)
grid_search.fit(X_scaled, y_train)

💡 Pro Tip: A good starting point for γ is 1 / (n_features * X.var()) — this matches scikit-learn's default 'scale' option.
