The RBF kernel, explained by playing with it

The Radial Basis Function (Gaussian) kernel turns distance into similarity. That one idea powers non-linear SVMs, Gaussian processes and kernel ridge regression. Move the sliders, drag the points and train a classifier in your browser to see how it works.

K(x, x′) = exp(−γ · ‖x − x′‖²)
Open the playground → How to tune γ and C Python package

01What each part means

Three pieces, one job: give two points a similarity score between 0 and 1.

‖x − x′‖²

Squared distance

How far apart the two points are in feature space. Because it depends only on distance, the kernel is radial: every direction counts equally, which is why feature scaling matters.

γ

Gamma, the inverse width

Controls how fast similarity decays. Large γ means only very close points count as similar. It relates to the Gaussian width σ by γ = 1 / (2σ²).

exp(−·)

Exponential decay

Maps distance 0 to similarity 1 and large distances to almost 0. The result is always in (0, 1], symmetric, and forms a positive-definite Gram matrix, so it is a valid kernel.

λ here plays the role of 1/C in an SVM: small λ (large C) trusts every point; large λ (small C) prefers a smoother function. Try Moons at γ ≈ 1, then push γ above 50 and λ down to 0.001: training accuracy hits 100% while leave-one-out accuracy drops. Then slide γ down to 0.01 to see underfitting.

05Why it works: the kernel trick

Many algorithms (SVMs, ridge regression, PCA) only ever need dot products between points. Replace those dot products with K and you get a non-linear model without building the features yourself.

Input space

Classes may be tangled, like two interleaved moons, so no straight line separates them.

Implicit feature map φ

The RBF kernel equals a dot product ⟨φ(x), φ(x′)⟩ in an infinite-dimensional space. You never compute φ.

Linear model there

A flat hyperplane in that space separates the classes. The solver only touches the n×n matrix of K values.

Curved boundary here

Mapped back, the hyperplane becomes the smooth, curved boundary you saw in the playground.

06Tuning γ and C properly

γ and C interact, so always search them together on a log scale, with scaling inside a pipeline so cross-validation stays honest.

SettingWhat you seeSymptomFix
γ too smallNear-linear, over-smooth boundaryTrain and test accuracy both low (underfitting)Increase γ, or increase C
γ too largeIslands around single pointsTrain ≈ 100%, test much lower (overfitting)Decrease γ, or decrease C
C too smallWide margin, many misclassified pointsUnderfitting, many support vectorsIncrease C
C too largeBoundary bends to fit every pointOverfitting, sensitive to noiseDecrease C
Good startgamma="scale" (= 1/n_features on standardized data) and C=1, then search γ and C each over about 10⁻³…10³.

A leak-free tuning recipe

from sklearn.model_selection import GridSearchCV, StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
import numpy as np

# Scaler INSIDE the pipeline: it is re-fit on each training fold (no leakage)
pipe = make_pipeline(StandardScaler(), SVC(kernel="rbf"))
grid = {
    "svc__gamma": np.logspace(-3, 2, 11),
    "svc__C":     np.logspace(-2, 3, 11),
}
search = GridSearchCV(pipe, grid, cv=StratifiedKFold(5, shuffle=True, random_state=0), n_jobs=-1)
search.fit(X_train, y_train)
print(search.best_params_, search.best_score_)
print("held-out test:", search.score(X_test, y_test))

Do

  • Standardize features. The kernel uses raw distances.
  • Search γ and C together on a log grid.
  • Keep a test set you never touch while tuning.
  • Use class weights or AUC/recall when classes are imbalanced.

Don't

  • Fit the scaler on all data before splitting (leakage).
  • Judge a model by training accuracy.
  • Run an exact kernel SVM on millions of rows. Use approximations.
  • Assume RBF beats linear on very high-dimensional sparse text.

When it is a good choice

  • Non-linear structure, moderate feature count.
  • Up to roughly 10⁴–10⁵ samples for exact SVMs.
  • Larger data: Nyström or Random Fourier Features plus a linear model.
  • Smooth regression and Gaussian-process style problems.

07Use it in Python

This repository ships a small, tested package with readable NumPy implementations (RBF kernel, gamma heuristics, kernel ridge, Random Fourier Features, Nyström) and reproducible examples.

# pip install "git+https://github.com/lunganlungpg/rbf-kernel-.git"
from rbf_kernel import rbf_kernel, median_heuristic_gamma, tune_rbf_svc

K = rbf_kernel(X, gamma=0.5)                  # n×n Gram matrix
g = median_heuristic_gamma(X)                 # data-driven starting gamma
search = tune_rbf_svc(X_train, y_train)        # scaled SVC + stratified grid search
print(search.best_params_, search.score(X_test, y_test))
